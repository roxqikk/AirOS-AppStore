# GameBOX App Store (GitHub)

Загружает список реальных файлов из папки `apps/` репозитория. Отображает только имена файлов вида `Files.js`, `Clock.js`.

- Нет каталога с несуществующими приложениями.
- Веб-страница позволяет скачать JS через raw.githubusercontent.com.
- ESP32 может использовать GitHub Contents API и скачивать только существующие файлы.

**Важно:** загрузка JavaScript-файла на ESP32 не означает, что он может запуститься. Для запуска нужен встроенный JS-интерпретатор (например, небольшой движок), безопасный интерфейс приложений и контроль свободной RAM. Рекомендуется проверка SHA-256, размера и доверенного источника до установки. Не выполняйте произвольный JS из интернета.

Папка `apps/` изначально пустая (с файлом .gitkeep). Добавьте `Files.js`, и он появится в магазине. Старый `flappybird.js` в корне репозитория не попадает в каталог автоматически.
